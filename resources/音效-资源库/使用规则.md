# 音效使用规则（AI 必读）

## 硬规则

1. **禁止自行合成 SFX。** 不要用正弦波 / 白噪声 / 包络 / numpy 拼出来的音效。
   程序合成音缺瞬态和材质，混进人声后"电子、飘、不像现场"，观众一听就出戏。
   反面教材：EP02 的 `bell/pop/click/whoosh/stamp/brush/tick/close` 8 条是合成的，已被判"听起来奇怪"。
2. **唯一取用位置**：
   ```
   /Users/jacky/Library/CloudStorage/坚果云-jackyshen@uperform.cn/优普丰大文件(默认不同步到本地)/02 通用市场开拓/05 市场运营活动/28 短视频策划/短视频脚本策划稿/随意口播系列/引擎-模板/resources/音效-资源库
   ```
3. **本库现在只有剪映官方音效**（5 类，约 20 个独立声音）。开工前先读 `音效索引.json`，按分类挑。
4. 库里没有需要的声音 → **明确告诉用户缺什么、用在哪个打点**，用户同意后从 Mixkit 直链补下并入本库。
5. **不要为了凑数自己合成。** 宁可少放音效，也不要放假的。

## 分类 → 用途对照

| 分类 | 适合当什么 |
|---|---|
| 开篇音效 | 开场 hook、大鼓/号角式开场 |
| 提示音 | 信息落点 click/pop、打字/计时 tick、轻确认 ding |
| 重点强调 | 重点重音 stamp、强调/落定 impact |
| 转场音效 | 转场 whoosh、段落切换 riser |
| 情绪音效 | 升华 bell、翻车/否定 error、人群反应 reaction、悬念 tension |

## cue 角色 → 先查哪个分类

| cue 角色 | 先查分类 | 备选 |
|---|---|---|
| click / pop / tick | `提示音/` | — |
| whoosh | `转场音效/` | — |
| stamp / 重点重音 | `重点强调/` | `情绪音效/` |
| bell / 升华 | `情绪音效/` | `重点强调/` |
| brush / close | `提示音/`、`情绪音效/` | — |

## 电平与用量

- 人声 -16 dBFS ｜ 铺底音效 -26 ~ -30 dBFS ｜ 重音 -18 dBFS
- 每 60 秒最多 3 次重音；提示音当标点用，压得很低
- 音效起点**削平对齐**到画面切换那一帧
